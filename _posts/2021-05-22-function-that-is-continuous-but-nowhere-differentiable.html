This discussion arises from the past paper of one of the unit in the University of Bristol. Specifically, it is question B, year 2015 of MATH10011 Analysis B.

Given any function \(f: \mathbb R \to \mathbb R\), it is very easy to list example where \(f\) is continuous at a point \(x=a\) but not differentiable there. For instance, \(f(x) = |x|\) at \(x=0\) is a very good example.

However, we can do even more, here is a function which is no where differentiable: take \(f: [0, 2\pi] \to \mathbb R\):

\(\displaystyle f(x) = \sum_{k = 1}^\infty 2^{-k}\cos\left(3^{-k}x\right)\)

We will try to layout the reason why we can establish this example, including issues of checking whether \(f\) is well-defined, including major theorems and some short proofs along the way.

Well-definedness

Firstly we will lay out some definitions.

Definition. Consider a sequence of functions \((g_n), g_n : [a, b] \to \mathbb R\), we would write
\(\displaystyle f = \sum_{k=1}^\infty g_k\) if, obviously, \(\displaystyle f(x) = \sum_{k=1}^\infty g_k(x)\). That means we would need the series \(\sum_{k=1}^\infty g_k(x)\) to converge in every \(x \in [a, b]\).

Now we would want to should the function indeed exists by checking the above condition. This can be easily done noting that \(g_k (x) = 2^{-k}\cos\left(3^{-k}x\right)\), and

\(0 \leq |2^{-k}\cos(3^{-k}x)| \leq 2^{-k}\)

for any integer \(k\), so by geometric series test we have absolute convergence in the series \(\sum_{k = 1}^\infty 2^{-k}\cos\left(3^{-k}x\right)\) for any \(x\), hence it is convergent and \(f(x)\) is well-defined for any \(x\).

Continuity

To investigate continuity we need the following definition and results:

Definition. A function \(f:[a, b] \to \mathbb R, \displaystyle f = \sum_{k=1}^\infty g_k\) is uniformly convergent if we consider the sequence of function \((f_n)\), with \(\displaystyle f_n(x) = \sum_{k=1}^n g_k(x)\), and \(f_n \to f\) uniformly.
Theorem (Weierstrass M-test). Using the above notation, if for every \(k \in \mathbb N\), there exists \(M_k \in \mathbb R\) such that \(|g_k(x)| < M_k\) and \(\displaystyle\sum_{k=1}^\infty M_k\) exists, then \(f\) is uniformly convergent and continuous on \([a, b]\).

It is now quite routine to check \(f\) is indeed continuous, because we only need to check the premise in the M-test. Specifically, as above, we can take \(M_k = 2^{-k}\), and again by geometric series test we are done.

Differentiability at x = 0

It would be the best (see why later) to investigate the reason behind nowhere differentiability of \(f\) by just investigating a single point, and it wouldn’t be better to choose \(x = 0\). Mostly because we know the value of \(f(0) = \displaystyle \sum_{k = 1}^\infty 2^{-k}\cos 0 = 1\).

Now let’s proceed the proof by contradiction, assuming \(f'(0)\) actually exists. Of course one would immediately whip out the definition \(\displaystyle f'(0) = \lim_{h \to 0}\dfrac{f(h)-f(0)}{h}\). But there is another way of dealing with this limit:

Theorem. If \((y_n)\) is a sequence such that \(y_n \to 0\), then the limit \(f'(0)\), if exists, should be equal to \(\displaystyle \lim_{m \to \infty}\dfrac{f(y_m)-f(0)}{y_m}\).

The proof is easy, just check that the definition collide in this case.

Now let’s look at \(f(y_m)\), it would be nice if we can get the \(\cos(3^{-k}x)\) part vanish, motivated by this, we let \(y_m = \left(\dfrac\pi 2\right)3^{-m}\), now we need to see that

\(\displaystyle f(y_m) = \sum_{k=1}^\infty2^{-k}\cos\left(3^{k}y_m\right) = \sum_{k=1}^m 2^{-k}\cos\left(3^{k-m} \left(\dfrac\pi 2\right) \right) + \sum_{k=m+1}^\infty 2^{-k}\cos\left(3^{k-m} \left(\dfrac\pi 2\right) \right)\)

The right hand side sum is very nice. This is because \(k > m\) so the term inside \(\cos\) is always a odd multiple of \(\dfrac{\pi}2\). Which means it cancels! Yay! Now we are only left with \(\displaystyle \sum_{k=1}^m 2^{-k}\cos\left(3^{k-m} \left(\dfrac\pi 2\right) \right)\). Unfortunately we cannot do further simplification, but we can bound this scary thing:

\(\displaystyle f(y_m) = \sum_{k=1}^m 2^{-k}\cos\left(3^{k-m} \left(\dfrac\pi 2\right) \right) \leq \sum_{k=1}^m 2^{-k} = 1-2^{-m}\)

Now we really want to dig into the derivative, because \(f(0) = 1, f(y_m) \leq 1-2^{-m}\), it would be better if we subtract them. This doesn’t matter since we are investigating \(\displaystyle \left|\dfrac{f(y_m)-f(0)}{y_m} \right|\) anyways, so we can switch signs as we like, formally:

\(\displaystyle \left|\dfrac{f(y_m)-f(0)}{y_m} \right| \geq \dfrac{f(0)-f(y_m)}{y_m} \geq \dfrac{1-( 1-2^{-m} )}{y_m} = \dfrac{2 \cdot 2^{-m}}{\pi 3^{-m}} = \frac{2}{\pi}\left(\frac32\right)^m\)

So now we have \(\displaystyle \lim_{m \to \infty}\dfrac{f(y_m)-f(0)}{y_m} = \frac{2}{\pi}\left(\frac32\right)^m = +\infty\), but if \(f'(0)\) exists, then the limit should exists as well! We finally reach a contradiction, and conclude

\(f(x)\) is not differentiable at \(x=0\).

Differentiability at other points…?

One might ask is there a way of extending the previous technique into other given points \(x=a\), however, we are face with two difficulty:

  1. If we consider a sequence \(z_m \to a\), We can’t effectively bound \(f(a)-f(z_m)\).
  2. With additional term in \(z_m\), taking \(m \to \infty\) might not be the result that we like.

So basically weird things happen in both the numerator and denominator, as a first year student, it is quite unfortunate I have to admit defeat here. Generally, given real numbers \(b > a > 1\) and define \(f: \mathbb R \to \mathbb R\)

\(f(x) = \sum_{k = 1}^\infty a^{-k}\cos\left(b^{-k}x\right)\)

It is understood that this function is always continuous and nowhere differentiable. The proof of continuity is very similar to that I had introduced (and is left as an exercise for the reader.), but the proof of nowhere differentiability, as you can see, is the real deal. Progress had been made, see

  • Brent Nelson’s elementary proof for the special case of \(b\) odd, and \(\dfrac{b}{a} > 1 + \dfrac{3\pi}{2}\).
  • Jon Johnsen’s proof of the general case, I think he used a lot of advanced analysis so be prepared.

Conclusion

Typing this up is probably not the wisest thing to do when you have your exam 2 days later, and you still haven’t finished all the revision planned. But this topic intrigued me a lot, and it is my pleasure to explore this and find the bound of what my “toolbox” can currently do.

Mathematically, it is also very shocking to see a smooth, uniformly convergent function can end up behaving in such a bad way, it is very counter-intuitive!
